## What Was Built

### Task 1: Backend Foundation

**`packages/db/src/schema/customer.ts`** — 4 Drizzle SQLite tables following auth.ts pattern:
- `customer`: user FK, industry (JSON text), targets (JSON), smtpConfig, plan enum
- `subscription`: Polar.sh polarId, plan, status enum (active/canceled/past_due), currentPeriodEnd
- `leadPipeline`: leadId, stage enum (new/scored/enriched/pitched/replied), score, contactedAt — indexed on customerId
- `apiKey`: keyHash (unique), name, lastUsed — indexed on customerId
- Full Drizzle relations (customer hasMany subscription/leadPipeline/apiKey)

**`packages/config/src/pricing.ts`** — PRICING_TIERS const with 3 tiers:
- Starter: $49/mo, 500 leads, `polar_starter_placeholder`
- Growth: $149/mo, 2000 leads, mostPopular: true, `polar_growth_placeholder`
- Enterprise: $499/mo, 10000 leads, `polar_enterprise_placeholder`

**`packages/auth/src/api-keys.ts`** — generateApiKey() → `sk_live_` + 32 random bytes base64url, hashApiKey() SHA-256, maskApiKey()

### Task 2: Sales Landing Page

Replaced infrastructure-focused page with conversion-optimized sales page:
- **Hero**: Green pulse badge "231,834 leads indexed · Live", gradient h1 "Qualified B2B Leads, Delivered by AI", Start Free Trial CTA → `/login?redirect=/onboarding`
- **Stats strip**: 231K+ Leads Indexed · 45x Faster Than Manual · 98% Email Enrichment Rate (motion fadeUp)
- **Feature bento**: 6 cards (Lead Scoring, Email Enrichment, AI Outreach, Pipeline Analytics, CRM Sync, Real-time Alerts) with hover gradient animation
- **Pricing section**: Maps PRICING_TIERS, Growth tier has "Most Popular" badge (absolute positioned, ring-1 ring-primary), CTA → Polar.sh checkout URL
- **Footer**: Privacy / Terms / Contact links
