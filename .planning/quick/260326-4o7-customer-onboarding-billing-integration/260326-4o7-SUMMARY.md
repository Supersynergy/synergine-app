## What Was Built

### Task 1: Onboarding Wizard + Activate API

**`/apps/web/src/routes/onboarding.tsx`** — 4-step wizard with:
- `beforeLoad` auth guard — unauthenticated users redirected to `/login?redirect=/onboarding`
- Step 1: Industry multi-select grid (7 options, toggle buttons)
- Step 2: Target criteria (location required, company size select, keywords optional)
- Step 3: SMTP config with "Test Connection" (calls `/api/onboarding/test-smtp`) + "Skip for now"
- Step 4: Review summary + "Activate Pipeline" button (indigo, calls `/api/onboarding/activate`)
- `AnimatePresence mode="wait"` wrapping each step with `x: 30 → 0 → -30` slide transitions

**`/apps/server/src/routes/onboarding.ts`** — Hono router:
- `POST /activate`: session auth → validate body → insert customer + apiKey → return `{ success, apiKey }`
- `POST /test-smtp`: nodemailer `createTransport` + `verify()` → always 200 with `{ success, error? }`

**`/apps/server/src/index.ts`** — mounted `api.route("/onboarding", onboarding)`

### Task 2: Billing Integration + Dashboard Billing Status

**`/apps/web/src/routes/pricing.tsx`** — Public `/pricing` route:
- `beforeLoad` fetches session non-throwing for email pre-fill
- 3-column responsive grid of pricing cards with CTA buttons
- CTA constructs `polarCheckoutUrl?customer_email={email}` then `window.location.href`
- Toast "Redirecting to checkout..." via sonner before redirect

**`/apps/server/src/routes/billing.ts`** — Hono router:
- `POST /webhook`: handles `checkout.completed` (upsert subscription + update customer.plan), `subscription.updated/created/canceled`; HMAC validation if `POLAR_WEBHOOK_SECRET` set; always returns `{ received: true }`
- `POST /checkout`: auth required → builds checkout URL with email → returns `{ checkoutUrl }`
- `GET /status`: auth required → Drizzle query customer + latest subscription → returns `{ plan, status, currentPeriodEnd, portalUrl }`

**`/apps/web/src/routes/dashboard.tsx`** — Added billing card:
- `useEffect` fetches `GET /api/billing/status` with credentials
- `<Skeleton>` while loading
- Shows plan Badge + status Badge (green=active, yellow=past_due, red=canceled) + next billing date + "Manage Billing →" link when subscribed
- Shows "No active subscription" + "View Plans" Button linking to `/pricing` when no subscription
